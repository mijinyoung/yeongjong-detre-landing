# 영종 디에트르 랜딩페이지 v14.0

광고를 실제로 송출한 뒤 어떤 매체·캠페인·소재·검색어가 상담을 만들었는지 더 정확히 확인하기 위한 실광고 운영 최적화 버전입니다.

## 광고 유입정보 신뢰성 강화

- 방문자가 분석 사용에 동의한 경우 최근 광고 유입정보를 30일 동안 유지합니다.
- 광고를 보고 방문한 뒤 브라우저를 닫았다가 다시 들어와 상담을 신청해도 최근 광고 유입값을 이어서 기록합니다.
- 분석 사용을 거부하거나 동의를 철회하면 장기 보관된 광고 유입정보를 즉시 삭제합니다.
- 분석 동의 전에는 기존과 동일하게 현재 방문 중에만 유입정보를 유지합니다.
- 첫 접속 주소를 전체 HTTPS 주소로 저장해 광고 주소와 캠페인값을 정확히 확인할 수 있도록 수정했습니다.
- 첫 화면에서 분석 동의를 선택한 직후에도 `landing_view` 측정이 빠지지 않도록 보강했습니다.

## 검색광고 키워드 기록

- `utm_term` 값을 Google Sheets의 `검색어` 열에 저장합니다.
- 관리자 목록에서 캠페인·광고소재와 함께 검색어를 확인할 수 있습니다.
- 관리자 검색창에서 검색어로 상담고객을 찾을 수 있습니다.
- CSV 내려받기에 검색어 열을 추가했습니다.

네이버·Google 광고 주소를 만들 때 관리자 화면의 `검색어` 입력란을 사용하면 됩니다.

## 관리자 광고 분석

- 유입경로 필터를 추가했습니다.
- 네이버, Google, Meta, 카카오, 직접 방문 등 특정 유입만 골라 볼 수 있습니다.
- 유입경로 필터와 상담 상태 필터를 함께 사용할 수 있습니다.
- 검색창 안내를 캠페인·검색어 중심으로 정리했습니다.

## 광고 송출 점검 강화

`/system-check`에서 Meta Conversions API를 사용할 때 `META_TEST_EVENT_CODE`가 남아 있는지 확인합니다.

운영 광고를 시작할 때 테스트 이벤트 코드가 남아 있으면 실제 광고 성과로 정상 집계되지 않을 수 있으므로, Meta 테스트가 끝난 뒤 해당 값을 비워 주세요.

## 배포 시 필수 작업

이번 버전은 Google Sheets에 `검색어` 열을 추가하므로 Apps Script 업데이트가 필요합니다.

1. `integrations/google-apps-script.gs` 전체 내용을 복사합니다.
2. 기존 Google Apps Script 내용 전체를 교체합니다.
3. `배포 → 배포 관리 → 수정 → 새 버전 → 배포`를 진행합니다.
4. 기존 웹 앱 주소와 `WEBHOOK_SECRET`은 그대로 유지합니다.

기존 고객 행과 기존 열은 유지되며, 누락된 `검색어` 열만 오른쪽 끝에 자동 추가됩니다.

## 광고 운영 확인 순서

1. `/admin`에서 매체·캠페인·소재·검색어를 넣어 광고 주소를 만듭니다.
2. 만든 주소를 새 창으로 엽니다.
3. 방문 분석 사용에 동의합니다.
4. 관심고객 테스트 접수를 한 번 완료합니다.
5. Google Sheets에서 유입경로·캠페인·광고소재·검색어를 확인합니다.
6. `/admin`에서 해당 유입경로 필터와 검색어 검색이 정상인지 확인합니다.
7. `/system-check`에서 `광고 송출 가능` 판정을 확인합니다.

## 개인정보 처리

30일 광고 유입 보관은 방문 분석 사용에 동의한 브라우저에만 적용됩니다. 이름과 전화번호는 상담 신청을 완료하기 전에는 이 저장값에 포함되지 않습니다.
