# 영종 디에트르 랜딩페이지 v17.0

접수 건수뿐 아니라 어느 매체·캠페인·광고소재가 실제 상담, 방문예약, 계약으로 이어지는지 비교할 수 있게 만든 광고 성과 최적화 버전입니다.

## 핵심 변경

- 관리자 화면에 `광고 유입·상담 성과` 리포트를 추가했습니다.
- 최근 7일·30일·90일·전체 기간을 선택할 수 있습니다.
- 매체·캠페인·광고소재별로 다음 수치를 비교합니다.
  - 문의 건수
  - 상담 진행 건수와 비율
  - 심화상담
  - 방문예약
  - 계약
- 5건 이상 데이터가 쌓이면 상담 반응을 `양호`, `계속 관찰`, `소재·타겟 점검`으로 표시합니다.
- 검색광고의 상위 검색어별 문의·상담·방문 반응을 표시합니다.
- 고객 이름과 전화번호가 포함되지 않은 광고 성과 CSV를 내려받을 수 있습니다.
- 모바일 관리자 화면에서도 캠페인 성과가 카드형으로 정렬됩니다.

## 반응 기준

- `상담 진행`: 연락완료, 상담중, 방문예약, 계약
- `심화상담`: 상담중, 방문예약, 계약
- `방문예약`: 방문예약, 계약

광고 반응 판정은 관리자가 고객의 `처리 상태`를 지속적으로 저장해야 정확해집니다.

## 주의할 점

- 리포트는 관리자 화면이 불러온 최근 200건을 기준으로 합니다.
- 광고비 지출 데이터는 포함되지 않습니다.
- 따라서 상담 품질을 비교하는 자료로 사용하고, 실제 비용 효율은 각 광고 매체의 지출 내역과 함께 확인해야 합니다.

## 적용 방법

1. v17 파일을 기존 GitHub Desktop 프로젝트에 덮어씁니다.
2. Commit·Push 후 Vercel 배포가 `Ready`가 될 때까지 기다립니다.
3. `/admin`에서 광고 성과 리포트와 기간 선택을 확인합니다.

v16 Apps Script를 이미 배포했다면 Google Apps Script는 다시 배포할 필요가 없습니다. Vercel 환경변수도 추가할 항목이 없습니다.
