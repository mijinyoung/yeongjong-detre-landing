# 영종 디에트르 랜딩페이지 v12.0

광고 송출 직전의 모바일 첫 화면, 콘텐츠 가독성, 전환 측정, 관리자 광고 분석을 한 번에 정리한 버전입니다.

## 핵심 개선

- 모바일 첫 화면 영상이 초기 화면에서 바로 자동재생되도록 영상 소스를 HTML에 직접 포함했습니다.
- 모바일 브라우저 복귀·화면 전환 뒤에도 음소거 자동재생을 다시 시도합니다.
- 자동재생이 지연되더라도 별도 재생 버튼은 표시하지 않고 일정 시간 재생을 다시 시도합니다.
- 모바일 영상 밝기를 높이고 촬영일 문구가 보이던 좌측 상단 가림 처리를 유지했습니다.
- 기존 공식 이미지와 영상 포스터를 활용한 `핵심 장면` 구간을 추가했습니다.
- 비슷한 내용을 반복하던 프리미엄·타임라인·분양안내·방문절차 구간은 숨겼습니다.
- `왜 지금인가` 구간은 다섯 항목에서 세 가지 핵심 가치로 줄였습니다.
- 커뮤니티 구간을 공식 이미지와 짧은 정보 카드 조합으로 바꿨습니다.
- 새 이미지를 추가하지 않고 기존 최적화 파일을 재사용해 다운로드 증가를 최소화했습니다.
- 모바일에서 단지배치도와 커뮤니티 자료가 잘리지 않도록 원본 비율을 유지합니다.
- 모바일 제목과 본문에 한글 단어 단위 줄바꿈을 적용해 한두 글자만 다음 줄로 밀리는 현상을 줄였습니다.
- 공식자료 탭 세 개가 좁은 화면에서도 잘리지 않고 한 줄에 정렬됩니다.

## 광고 전환 측정

- 관심고객 폼에 처음 입력을 시작한 시점을 `lead_form_start`로 측정합니다.
- 제출 버튼을 누른 시점을 `lead_submit_attempt`로 측정합니다.
- 기존 완료 이벤트와 함께 `폼 시작 → 제출 시도 → 접수 완료` 흐름을 비교할 수 있습니다.
- 새 핵심 장면 구간의 노출도 `section_view`로 측정합니다.
- 방문분석 동의 전에는 위 이벤트가 외부 분석 도구로 전송되지 않습니다.

## 관리자 화면·광고 데이터

- 관리자 검색과 CSV에 매체유형, 캠페인, 광고소재를 추가했습니다.
- 주요 유입경로에 `utm_source / utm_medium`을 함께 표시합니다.
- 상위 캠페인·광고소재를 관리자 리포트에서 바로 확인할 수 있습니다.
- Google Sheets에 매체유형, Google 클릭 ID, Meta 클릭 ID를 보관하도록 Apps Script를 확장했습니다.
- 클릭 ID는 관리자 목록에 노출하지 않고 광고 유입 점검을 위한 원본 시트에만 저장합니다.

## 배포 전 필수 작업

이번 버전은 Google Sheets 열이 추가되므로 `integrations/google-apps-script.gs`의 전체 내용을 기존 Apps Script에 덮어쓴 뒤 새 버전으로 다시 배포해 주세요. 기존 데이터와 기존 열은 유지되며 새 열만 오른쪽에 추가됩니다.

Vercel 환경변수는 기존 값을 그대로 사용합니다. 광고 주소에는 아래 UTM 항목을 일관되게 넣어야 관리자 광고 분석이 정확합니다.

```text
utm_source=naver
utm_medium=cpc
utm_campaign=캠페인명
utm_content=광고소재명
```

## 모바일 자동재생

영상은 모바일에서 음소거·인라인 방식으로 자동재생합니다. 초기 로딩이나 화면 복귀 과정에서 재생이 지연되면 8초 동안 자동으로 재시도하며, 사용자가 화면을 스크롤하거나 터치하는 순간에도 별도 버튼 없이 영상 재생만 다시 요청합니다.
