# 영종 디에트르 랜딩페이지 v8.2

## 주요 변경사항
- 스크롤 이후 노출되는 플로팅 상담 버튼으로 첫 화면 방해 최소화
- 모바일 하단 버튼의 전화/등록 목적과 보조 문구 개선
- 주요 CTA 버튼 hover/press 반응 및 disabled 상태 강화
- 상담 모달에 무료 상담, 목적 외 사용 없음, 취소 가능 안심 정보 추가
- 감사 페이지 전화 클릭 전환 추적 보강
- 감사 페이지에 접수 후 상담 진행 순서 추가
- 모바일 안전영역(safe-area) 대응

## 배포
GitHub Desktop에서 변경사항을 커밋한 뒤 Push origin을 누르면 Vercel이 자동 배포합니다.
