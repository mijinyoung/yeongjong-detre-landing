# 영종 디에트르 라 메르 랜딩페이지 v20.0

첫 화면의 방문 분석 선택창을 작고 부담 없는 형태로 정리하고, 6개 주거 타입 평면도에서 분양 금액·추가선택품목 안내 버튼을 비노출 처리한 버전입니다.

## 핵심 변경사항

- 최초 방문 시 표시되는 분석 동의창을 작은 하단 안내창으로 축소했습니다.
- 문구와 버튼을 간결하게 정리하고 `거부`와 `동의` 선택권은 그대로 유지했습니다.
- 모바일에서는 전화상담·관심고객 등록 고정 버튼 위에 겹치지 않도록 배치했습니다.
- 거부하더라도 관심고객 등록과 UTM 기반 유입경로 저장은 정상 동작합니다.
- Meta Pixel과 Google Analytics는 동의한 방문자에게만 실행됩니다.
- 84A, 84B, 104A, 104B, 113A, 113B 평면도 우측 상단의 다음 네 줄을 모두 비노출 처리했습니다.
  - 공급 금액
  - 발코니 확장 금액
  - 시스템에어컨
  - 타입별 추가선택품목
- 일반 평면도 화면과 확대 화면에 동일하게 적용했습니다.
- 도면의 방 배치, 면적, 치수와 설명은 변경하지 않았습니다.

## 배포 시 추가 설정

- Vercel 환경변수 변경 없음
- Google Apps Script 기능 변경 없음
- 기존처럼 GitHub Desktop에서 커밋 후 Push하면 Vercel이 자동 배포합니다.
