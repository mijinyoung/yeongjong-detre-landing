# 영종 디에트르 라 메르 v9.3

v9.3은 운영 점검 정보 보호, 장애 추적성, 메인 영상 가독성을 강화한 버전입니다.

## 주요 변경사항

- `/api/health`의 상세 연동 상태를 `SYSTEM_CHECK_TOKEN` 인증 뒤에만 제공
- 인증하지 않은 상태에서는 버전과 기본 정상 여부만 반환
- `/system-check`에 운영 점검 비밀번호 입력 화면 추가
- API 응답에 고유 요청 ID를 추가해 오류 문의와 서버 로그를 쉽게 대조
- 상태 및 테스트 API 응답에 `no-store` 캐시 정책 적용
- 연동 테스트 실패 시 외부 서비스의 내부 오류 내용을 화면에 직접 노출하지 않도록 정리
- 메인 영상 좌측 상단에 포함된 촬영일 등의 원본 문구를 그라데이션 마스크로 가림
- 모바일 메인에서 영상이 먼저 보이도록 문구 영역을 하단으로 재구성
- 모바일 제목, 버튼, 핵심 수치 영역을 압축하고 중복 설명을 숨겨 PC 화면과 비슷한 영상 중심 인상으로 개선
- 패키지 버전 `9.3.0` 반영

## 환경변수 확인

Vercel의 Production 환경에 아래 값이 설정되어 있어야 운영 점검 상세 화면을 사용할 수 있습니다.

```text
SYSTEM_CHECK_TOKEN=본인만 아는 충분히 긴 비밀번호
```

기존 Google Sheets, 문자, 관리자, 광고 측정 환경변수는 변경하지 않습니다.

## 운영 점검

배포 후 아래 주소에서 `SYSTEM_CHECK_TOKEN` 값을 입력합니다.

```text
https://홈페이지주소/system-check
```

인증 전에는 상세 연동 설정 상태가 표시되지 않으며, 인증 후에만 Google Sheets, 문자, Meta 및 Google 측정 연결 상태를 확인할 수 있습니다.
