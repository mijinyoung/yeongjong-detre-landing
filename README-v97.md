# 영종 디에트르 라 메르 v9.7

v9.7은 관리자 화면에 접수 추이와 유입 성과, 미처리 상담 알림을 추가한 운영 리포트 버전입니다.

## 주요 변경사항

- 최근 7일 관심고객 접수 추이 막대그래프 추가
- 최근 7일 총 접수 건수 표시
- 네이버·Meta·직접 방문 등 주요 유입경로 상위 5개 표시
- 유입경로별 접수 건수와 비율 표시
- 접수 후 24시간 이상 `신규` 상태인 고객 자동 감지
- 미처리 신규 상담 알림과 바로보기 버튼 추가
- 상태 필터에 `24시간 미처리` 항목 추가
- 모바일 관리자 화면에서 리포트·알림을 세로형으로 재배치
- 그래프에 날짜별 접수 건수 접근성 설명 추가
- 패키지 버전 `9.7.0` 반영

## 관리자 사용 방법

1. `https://홈페이지주소/admin`에 접속합니다.
2. 관리자 비밀번호를 입력합니다.
3. 최근 7일 접수 추이와 주요 유입경로를 확인합니다.
4. 미처리 알림이 표시되면 `미처리 고객 보기`를 누릅니다.
5. 고객에게 연락한 뒤 상태와 상담 메모를 저장합니다.

## 데이터 기준

- 리포트는 관리자 화면에서 불러온 최근 200건을 기준으로 계산합니다.
- 7일 추이는 접수 등록일시를 기준으로 집계합니다.
- 미처리 상담은 접수 후 24시간 이상 `신규` 상태인 고객입니다.
- 유입경로가 없으면 캠페인명 또는 `직접 방문`으로 집계합니다.
