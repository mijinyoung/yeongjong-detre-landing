# 영종 디에트르 랜딩페이지 v9.1

## 목표

v9.1은 공개 API와 관리자 도구의 입력 경계를 강화하고, 실제 모바일·관리자 화면 검증에서 발견된 접근성 문제를 보완한 운영 보안 버전입니다.

## 주요 변경사항

### 관심고객 API 보호

- `application/json` 요청만 허용하며 잘못된 형식에는 415를 반환합니다.
- 선언된 크기와 실제 본문 크기를 모두 검사해 16KB를 넘는 요청에는 413을 반환합니다.
- 잘못된 JSON을 서버 오류가 아닌 사용자 요청 오류(400)로 처리합니다.
- 이름·전화번호·유입정보·광고 식별자·URL의 형식과 최대 길이를 서버에서 제한합니다.
- 요청 객체 전체를 저장하지 않고 허용된 필드만 정제해 Google Sheets와 연동 서비스로 전달합니다.
- 클라이언트가 전달한 접수시각 대신 서버 접수시각을 사용합니다.
- URL은 HTTP/HTTPS 형식만 허용하고 제어문자를 제거합니다.

### 관리자 보안

- 동일 IP에서 관리자 비밀번호를 15분 동안 10회 이상 틀리면 일시적으로 접근을 제한합니다.
- 차단 응답에 429 상태와 `Retry-After`를 제공합니다.
- 관리자 요청 형식과 비밀번호 최대 길이를 제한합니다.
- CSV 다운로드 값이 `=`, `+`, `-`, `@` 등으로 시작할 때 수식으로 실행되지 않도록 보호합니다.
- 모든 API 응답에 `Cache-Control: no-store`를 적용합니다.

### 캐시 및 보안 헤더

- HTTPS 운영 환경에 HSTS 헤더를 추가했습니다.
- 고정 파일명을 사용하는 이미지·영상에 1년 `immutable` 캐시가 적용되던 충돌을 수정했습니다.
- 이미지는 1일, 영상은 7일 캐시 후 백그라운드 재검증하도록 변경했습니다.

### 접근성 및 오류 복구

- 관리자, 운영점검, 접수완료 화면에 본문 바로가기 대상 ID를 추가했습니다.
- 한국어 사용자용 404 페이지를 추가했습니다.
- 렌더링 오류 발생 시 다시 시도하거나 홈페이지로 이동할 수 있는 오류 화면을 추가했습니다.
- 오류 화면 버튼을 기존 완료 화면과 동일한 디자인으로 정리했습니다.

## 검증 결과

- `npm ci`: 성공
- `npx tsc --noEmit`: 성공
- `npm run lint`: 성공, 오류 및 경고 0개
- `npm run build`: 성공
- API 점검: 상태 조회 200, 잘못된 형식 415, 잘못된 JSON 400, 과대 요청 413, 로컬 정상 접수 200
- 모바일 브라우저 390×844: 가로 넘침 없음, 한국어 제목·필수 입력·영상 지연 로딩 확인
- 관리자 화면: 본문 바로가기 대상, 제목, 비밀번호 설명 확인
- 404 화면: 한국어 안내와 홈페이지 복귀 링크 확인

## 배포 안내

- Google Apps Script 변경은 없으므로 다시 배포할 필요가 없습니다.
- 기존 Vercel 환경변수는 그대로 유지합니다.
- 배포 후 `/api/health`에서 `version`이 `9.1.0`인지 확인합니다.

## 의존성 보안 참고

v9.0에서 확인한 Next.js 16.2.12 내부 `postcss`·`sharp` 전이 의존성의 npm 감사 경고는 유지됩니다. 감사 도구가 제시한 자동 수정이 비호환 Next.js 다운그레이드이므로 강제 적용하지 않았습니다.
