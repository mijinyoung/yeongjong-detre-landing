# 영종 디에트르 라 메르 v9.9

v9.9는 정식 운영 전 종합 QA 버전입니다. 접수 데이터 유실 방지, Google Sheets 보안, 관리자 개인정보 보호, 모바일 메뉴, 폼 접근성, 영상 성능과 SEO 설정 충돌을 우선 개선했습니다.

## 핵심 변경사항

### 접수 저장 신뢰성

- Google Sheets 저장 연동이 없거나 인증값이 빠진 상태에서는 고객에게 성공으로 표시하지 않습니다.
- Google Sheets 저장이 완료된 이후에만 문자·Meta 전환 후처리를 진행합니다.
- 개발 중 저장 연동 없이 폼 흐름만 확인할 때 사용할 수 있는 `LEAD_TEST_MODE`를 추가했습니다.
- 메모리 기반 요청 제한·중복 기록의 만료 데이터를 정리해 장시간 실행 시 불필요한 누적을 줄였습니다.
- SOLAPI와 Meta 전환 API 요청에 8초 제한 시간을 적용했습니다.

### Google Sheets 보안

- Apps Script 인증값이 비어 있거나 기본 문구인 경우 요청을 무조건 거부하도록 변경했습니다.
- Apps Script의 스크립트 속성 `WEBHOOK_SECRET` 사용을 권장 방식으로 적용했습니다.
- 관리자 목록 요청을 URL 쿼리가 아닌 인증된 POST 요청으로 변경해 비밀값이 주소·로그에 남지 않도록 했습니다.
- 이름·유입경로·메모 등 외부 입력이 Sheets 수식으로 실행되지 않도록 방어 처리를 추가했습니다.
- 연동 테스트가 Apps Script의 `{ ok: false }` 응답을 성공으로 오판하던 문제를 수정했습니다.

### 관리자 개인정보 보호

- 관리자 목록 API는 전화번호를 서버에서 마스킹한 상태로만 전달합니다.
- `번호 보기`를 누른 고객의 전화번호만 별도 인증 요청으로 조회합니다.
- 전화번호 개별 조회 기록을 서버 로그에 남깁니다.
- CSV에도 마스킹된 전화번호만 포함합니다.
- 수동·자동 잠금 시 진행 중인 조회·저장·번호 확인 요청을 취소하고, 늦게 도착한 응답이 잠긴 화면을 다시 여는 문제를 차단했습니다.
- 저장 성공과 실패 안내의 색상·알림 역할을 구분했습니다.
- 모바일 가로 스크롤 표에 키보드 접근 가능한 영역명과 초점 표시를 추가했습니다.

### 폼·키보드 접근성

- 이름은 서버와 동일하게 두 글자 이상 입력하도록 검증합니다.
- 이름·휴대폰·개인정보 동의 항목별 오류 문구, `aria-invalid`, 오류 연결을 추가했습니다.
- 제출 시 첫 번째 오류 항목으로 키보드 초점이 이동합니다.
- 상담창 제출 중에는 닫기·재열기를 막아 뒤늦은 완료 이동과 중복 제출을 방지합니다.
- 상담창을 다시 열 때 이전 전화번호를 초기화합니다.
- 상담창, 개인정보 안내, 이미지 확대, 모바일 메뉴, 분석 설정에 초점 순환·Escape 닫기·호출 버튼 초점 복귀를 적용했습니다.
- 상담창 안에서 개인정보 안내를 연 뒤 Escape를 눌러도 상담창까지 함께 닫히지 않습니다.
- 공식자료·평면·홍보영상 탭에 좌우 방향키, Home, End 이동을 추가했습니다.

### 모바일·영상 성능

- 모바일 메뉴가 상단 헤더 높이만큼만 열리던 문제를 수정하고 실제 화면 전체 높이로 표시되도록 변경했습니다.
- 첫 화면 영상은 데이터 절약 모드 또는 동작 감소 설정을 확인한 뒤에만 소스를 연결합니다.
- 일반 모바일 환경에서는 기존처럼 배경 영상이 자동재생되며, 차단된 환경에는 수동 재생 버튼이 표시됩니다.
- 아래쪽 홍보영상은 `preload="none"`을 유지하면서 검색엔진이 소스를 발견할 수 있도록 초기 HTML에 영상 주소와 포스터를 제공합니다.
- 반응형 랜드마크 이미지에 `sizes`를 추가하고 확대 모달의 불필요한 우선 로딩을 제거했습니다.

### SEO 충돌 정리

- `/admin`, `/system-check`, `/thank-you`는 크롤링은 허용하되 각 페이지의 `noindex`를 읽을 수 있도록 robots 충돌을 제거했습니다.
- 홈페이지 전용 canonical·Open Graph·Twitter 설정을 루트 레이아웃에서 홈페이지로 이동해 관리자 페이지에 상속되지 않도록 했습니다.
- 운영 Vercel 배포에서는 `NEXT_PUBLIC_SITE_URL`이 없거나 HTTPS가 아니면 빌드가 실패하도록 보호했습니다.
- 사이트맵에 대표 이미지와 두 홍보영상 정보를 추가했습니다.
- 실제 게시일을 확인할 수 없는 불완전한 `VideoObject` 구조화 데이터는 제거했습니다. 실제 게시일이 확인되면 다시 추가할 수 있습니다.

## 배포 전 필수 설정

### 1. Google Apps Script 업데이트

`integrations/google-apps-script.gs` 전체 내용을 기존 Apps Script에 덮어씁니다.

Apps Script의 **프로젝트 설정 → 스크립트 속성**에서 아래 항목을 추가합니다.

```text
WEBHOOK_SECRET
```

값은 Vercel의 `GOOGLE_SHEET_WEBHOOK_SECRET`과 동일하게 입력합니다. 기존에 `WEBHOOK_SECRET`만 사용 중이라면 같은 값을 Apps Script 스크립트 속성에 입력해도 호환됩니다.

코드 저장 후 **배포 → 배포 관리 → 수정 → 새 버전 → 배포**를 진행합니다.

### 2. Vercel 환경변수 확인

```text
NEXT_PUBLIC_SITE_URL=https://실제-운영-주소
GOOGLE_SHEET_WEBHOOK_URL=기존-Apps-Script-웹앱-주소
GOOGLE_SHEET_WEBHOOK_SECRET=32자-이상의-비밀값
```

- `NEXT_PUBLIC_SITE_URL`은 실제 운영 대표 주소와 정확히 일치해야 하며 HTTPS여야 합니다.
- `LEAD_TEST_MODE`는 운영 Vercel에 추가하지 마세요.
- 별도 문자 웹훅을 사용한다면 `SMS_WEBHOOK_SECRET`을 별도로 설정하는 것을 권장합니다.
- 이전 `WEBHOOK_SECRET`은 호환을 위해 계속 지원합니다.
