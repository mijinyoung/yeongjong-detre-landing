# 영종 디에트르 랜딩페이지 v9.2

## 목표

v9.2는 모바일 첫 화면의 불필요한 미디어 다운로드를 줄이고, 배포 파일과 소셜 공유 이미지의 용량을 최적화한 성능 개선 버전입니다.

## 주요 변경사항

### 첫 화면 영상 최적화

- 히어로 영상의 HTML 자동재생을 제거하고 화면 초기화 후 재생하도록 변경했습니다.
- 영상 `preload`를 `none`으로 변경해 포스터가 먼저 표시되도록 했습니다.
- 데이터 절약 모드 또는 동작 줄이기 설정이 켜진 환경에서는 히어로 영상을 자동 재생하지 않습니다.
- 브라우저 탭이 보이지 않을 때 영상을 일시정지하고 다시 보일 때 재생합니다.
- 히어로 배경과 영상 포스터가 동일 파일을 사용하도록 해 중복 이미지 다운로드를 제거했습니다.

### 하단 홍보영상 지연 로딩

- 홍보영상 영역이 화면 100px 근처에 도달하기 전에는 포스터와 MP4 소스를 DOM에 연결하지 않습니다.
- 영역에 가까워지면 포스터와 소스를 한 번만 연결합니다.
- 영상 자체는 기존처럼 재생 버튼을 누르기 전까지 다운로드하지 않도록 `preload="none"`을 유지합니다.

### 이미지 및 배포 용량 최적화

- 2.24MB 대표 PNG를 1200×630, 138KB의 소셜 공유용 JPEG로 교체했습니다.
- Open Graph, Twitter, 구조화 데이터가 새 대표 이미지를 사용합니다.
- 단지 홍보영상 포스터를 458KB에서 285KB로 최적화했습니다.
- 코드에서 사용하지 않는 대형 이미지 8개, 총 13.82MB를 제거했습니다.
- `public` 폴더 총용량을 약 66.6MB에서 52.6MB 수준으로 줄였습니다.
