# 영종 디에트르 라 메르 v9.5

v9.5는 모바일 메인 영상과 홍보영상의 초기 표시 속도, 캐시 효율을 개선한 버전입니다.

## 주요 변경사항

- 메인 영상 원본이 모바일 호환 H.264 형식인지 확인
- 영상 스트리밍 시작 정보가 파일 앞부분에 배치된 정상 파일인지 확인
- 메인 영상 포스터를 WebP로 최적화
- 브랜드·단지 홍보영상 포스터를 WebP로 최적화
- 영상과 포스터 주소에 v9.5 버전을 반영해 이전 배포 캐시와 충돌 방지
- 버전이 지정된 영상·포스터에 1년 장기 캐시 적용
- 일반 분양 이미지는 업데이트 가능성을 고려해 기존 재검증 캐시 유지
- 하단 홍보영상은 화면 근처에 도달하기 전까지 영상과 포스터를 요청하지 않는 지연 로딩 유지
- 구조화 데이터의 영상 대표 이미지도 최적화된 WebP로 변경
- 패키지 버전 `9.5.0` 반영

## 용량 개선

- 메인 영상 포스터: 약 210KB → 약 75KB
- 브랜드 영상 포스터: 약 170KB → 약 47KB
- 단지 영상 포스터: 약 285KB → 약 219KB
- 영상 포스터 합계: 약 665KB → 약 342KB

메인 영상은 약 2.6MB로 이미 충분히 작고 모바일 호환 형식이어서, 화질 저하가 생기는 재압축은 하지 않았습니다.

## 검증 결과

- TypeScript 검사 통과
- ESLint 검사 통과
- Next.js 16.2.12 프로덕션 빌드 통과
- 메인 영상 자동재생 및 재생 오류 없음 확인
- WebP 포스터 적용 확인
- 영상의 구간 전송 지원과 장기 캐시 헤더 확인
- 하단 홍보영상의 화면 진입 전·후 지연 로딩 확인
