# 영종 디에트르 라 메르 v9.8

v9.8은 관리자 화면에 표시되는 고객 개인정보 보호를 강화한 버전입니다.

## 주요 변경사항

- 관리자 목록의 휴대폰 번호를 기본 마스킹
- `010-****-5678` 형식으로 안전하게 표시
- 상담할 고객의 전화번호만 `번호 보기`로 개별 확인
- 번호를 확인한 경우에만 전화 연결 링크 제공
- 확인한 번호를 다시 가리는 `숨기기` 기능 추가
- 관리자 화면 상단에 `관리자 잠금` 버튼 추가
- 수동 잠금 시 비밀번호, 고객 목록, 메모 초안, 검색 조건을 즉시 제거
- 15분 동안 사용하지 않으면 관리자 화면 자동 잠금
- 마우스·키보드·터치·스크롤 활동 시 잠금 시간 갱신
- 관리자 개인정보 보호 모드 안내 추가
- `/admin`, `/system-check`에 브라우저 캐시 금지 적용
- 관리자·점검 페이지의 검색 보관과 아카이브 차단 헤더 추가
- 패키지 버전 `9.8.0` 반영

## 관리자 사용 방법

1. `https://홈페이지주소/admin`에 접속합니다.
2. 관리자 비밀번호를 입력합니다.
3. 전화가 필요한 고객만 `번호 보기`를 누릅니다.
4. 확인이 끝나면 `숨기기` 또는 상단 `관리자 잠금`을 누릅니다.
5. 15분 동안 사용하지 않으면 자동으로 잠기며 다시 비밀번호를 입력해야 합니다.

CSV 다운로드 파일에는 업무 처리를 위해 기존과 동일하게 전체 전화번호가 포함됩니다. 내려받은 파일은 외부에 공유하지 않고 사용 후 안전하게 보관하거나 삭제해 주세요.
