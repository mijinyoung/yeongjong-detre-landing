# v6.0 - 상담북 기반 콘텐츠 반영

- 상담북 실제 단지배치도, 랜드마크 디자인, 시스템 프리미엄 이미지 반영
- 기존 개념 평면도를 상담북의 실제 84A·84B·104A·104B·113A·113B 평면 이미지로 교체
- 공식 자료 탭형 섹션 추가
- 기존 상담 접수, UTM, Meta Pixel, GA4, thank-you 기능 유지

## 적용

전체 프로젝트를 기존 폴더에 덮어쓴 뒤:

```bash
npm install
npm run dev
```

확인 후:

```bash
git add .
git commit -m "Release v6.0 brochure-based content"
git push
```
