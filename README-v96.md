# 영종 디에트르 라 메르 v9.6

v9.6은 관리자 상담 처리 기능과 모바일 메인 영상 밝기를 개선한 버전입니다.

## 주요 변경사항

- 관리자 화면에서 고객별 상담 처리 상태 변경
- `신규·연락완료·상담중·방문예약·계약·보류` 상태 제공
- 고객별 상담 메모 입력 및 Google Sheets 저장
- 변경된 행만 저장 버튼이 활성화되도록 처리
- 저장 중·저장 완료 상태와 접근성 안내 추가
- 상담 상태별 목록 필터 추가
- CSV 파일에 상담 메모 포함
- Google Apps Script에 상담 상태·메모 갱신 기능 추가
- 관리자 저장 API의 입력값 검증, 인증, 시간 제한, 요청 ID 적용
- 모바일 메인 영상 상단 그라데이션을 밝게 조정
- 모바일 제목과 버튼 뒤쪽은 가독성을 위해 필요한 대비 유지
- 패키지 버전 `9.6.0` 반영

## Google Apps Script 업데이트

이번 버전은 아래 파일의 Apps Script 재배포가 필요합니다.

```text
integrations/google-apps-script.gs
```

1. Google Sheets에서 `확장 프로그램 → Apps Script`를 엽니다.
2. 기존 코드를 v9.6 파일 내용 전체로 교체합니다.
3. 기존에 입력했던 `WEBHOOK_SECRET` 값을 다시 확인합니다.
4. `배포 → 배포 관리`를 엽니다.
5. 현재 웹 앱의 수정 버튼을 누르고 `새 버전`으로 배포합니다.
6. 기존 웹 앱 주소는 그대로 유지합니다.

Apps Script를 재배포하지 않으면 관리자 목록 조회는 가능하지만 상태와 상담 메모 저장은 동작하지 않습니다.

## 관리자 사용 방법

1. `https://홈페이지주소/admin`에 접속합니다.
2. 관리자 비밀번호를 입력합니다.
3. 고객 행에서 처리 상태와 상담 메모를 수정합니다.
4. 오른쪽 `저장` 버튼을 누릅니다.
5. `완료` 표시가 나오면 Google Sheets 저장이 끝난 것입니다.
