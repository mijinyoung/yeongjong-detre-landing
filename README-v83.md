# 영종 디에트르 랜딩페이지 v8.3

## 추가 기능
- `/admin` 비밀번호 보호 관리자 대시보드
- Google Sheets 최신 접수 200건 조회
- 전체 누적, 오늘 접수, 신규 상담 통계
- 이름·전화번호·유입경로 검색
- 전화번호 바로 연결 및 CSV 내려받기
- 검색엔진 비노출 설정

## 배포 전 필수 설정
1. `integrations/google-apps-script.gs` 전체를 기존 Apps Script에 덮어씁니다.
2. Apps Script에서 **새 버전으로 웹 앱 재배포**합니다.
3. Vercel 환경변수에 `ADMIN_DASHBOARD_TOKEN`을 추가합니다. 20자 이상의 비밀번호를 권장합니다.
4. 배포 후 `https://내주소/admin`에서 비밀번호를 입력해 확인합니다.

## 보안
- 관리자 비밀번호는 서버에서만 검증합니다.
- Google Sheets 비밀값과 웹앱 주소는 브라우저에 노출하지 않습니다.
- 고객정보가 포함되므로 관리자 주소와 비밀번호를 공유하지 마세요.
