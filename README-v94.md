# 영종 디에트르 라 메르 v9.4

v9.4는 모바일 메인 영상 재생 대응과 관리자 운영 화면 품질을 강화한 버전입니다.

## 주요 변경사항

- 메인 영상에 모바일 자동재생 조건인 `muted`, `playsInline`, `autoPlay`를 명시
- 모바일 브라우저가 자동재생을 차단하면 `배경 영상 재생` 버튼 표시
- 영상 로딩 완료 시 자동재생을 다시 시도하고, 탭 복귀 시 재생 상태 복구
- 아이폰 호환성을 위해 영상 요소의 음소거 속성을 실행 시점에도 재확인
- 데이터 절약 모드와 동작 줄이기 환경에서는 포스터를 먼저 보여주고 수동 재생 제공
- 모바일 영상 초기 준비를 위해 preload를 `metadata`로 조정
- 관리자 화면에 문자 발송 실패 건수 표시
- 전체·신규 상담·문자 실패 상태 필터 추가
- 검색 결과 건수와 빈 접수 안내 추가
- 관리자 조회 요청에 10초 제한과 친절한 오류 안내 적용
- 관리자 API에 고유 요청 ID와 `no-store` 응답 정책 적용
- 상담 접수 요청 시간을 15초로 조정
- 오프라인 및 네트워크 연결 실패 안내 개선
- 패키지 버전 `9.4.0` 반영

## 모바일 영상 안내

일반적인 모바일 브라우저에서는 메인 영상이 음소거 상태로 자동재생됩니다. 다만 아래 환경에서는 운영체제나 브라우저가 자동재생을 차단할 수 있습니다.

- 아이폰 저전력 모드
- 데이터 절약 모드
- 사용자가 동작 줄이기를 설정한 경우
- 브라우저에서 자동재생을 제한한 경우

이 경우 영상 위에 나타나는 `배경 영상 재생` 버튼을 한 번 누르면 재생할 수 있습니다.

## 관리자 화면

기존과 동일하게 아래 주소에서 접속합니다.

```text
https://홈페이지주소/admin
```

Vercel의 `ADMIN_DASHBOARD_TOKEN` 값은 그대로 사용합니다. Google Apps Script 수정은 필요하지 않습니다.
