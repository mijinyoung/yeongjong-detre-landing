# v5.0 Premium Foundation

- Hero 전면 리디자인
- 네이비·골드·아이보리 디자인 시스템 통일
- 모바일 우선 Hero 및 CTA 개선
- `왜 지금 영종인가` 핵심 가치 섹션 신규 추가
- 정보 순서를 설득 중심으로 재배치
- 기존 상담 접수, 전환 페이지, 분석 이벤트 기능 유지

## 적용

전체 파일을 기존 프로젝트에 덮어쓴 뒤:

```bash
npm install
npm run dev
```

확인 후:

```bash
git add .
git commit -m "Release v5.0 premium foundation"
git push
```
